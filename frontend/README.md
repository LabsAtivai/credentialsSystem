# Snov Account Manager — Frontend

Painel administrativo em Vue 3 + TypeScript + Vite.

Documentação completa (arquitetura, instalação, variáveis de ambiente, Docker) no [README da raiz do projeto](../README.md).

## Comandos

```bash
npm install
npm run dev      # servidor de desenvolvimento
npm run build    # type-check + build de produção
npm run preview  # serve o build de produção localmente
```
